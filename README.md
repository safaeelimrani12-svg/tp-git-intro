# TP Git & GitHub — WebStart

## 1. Nom et objectif du projet

**Nom :** WebStart

**Objectif :** Créer une page web simple pour découvrir Git et GitHub, suivre les modifications et apprendre à travailler avec les branches et les fusions.

## 2. Technologies utilisées

- HTML5
- CSS3
- Git
- GitHub

## 3. Instructions pour ouvrir la page

1. Cloner le dépôt GitHub.
2. Ouvrir le dossier du projet.
3. Ouvrir le fichier `index.html` dans un navigateur web.

## 4. Évolutions enregistrées dans Git

- Création de la page HTML initiale.
- Modification du style et du slogan principal.
- Création de branches et résolution d'un conflit de fusion.
